## 🚀 O que tem aqui?

### 🛠️ Git Config
Otimizado para ser rápido e visual.
- **Aliases Pro:** `git lg` para um log em árvore colorido, `git ac` para add e commit em um comando só.
- **Auto-correção:** O Git corrige pequenos erros de digitação automaticamente.
- **Auto-setup:** Cria automaticamente a branch no remoto ao dar push.

### 🐚 Bash Aliases
Atalhos para o terminal focados em agilidade:
- **Navegação:** Atalhos curtos para pular entre pastas.
- **Full-Stack:** Comandos encurtados para Docker, Node.js e Python.
- **System:** Facilidades para o Debian e monitoramento do hardware (Dell Inspiron 15).
